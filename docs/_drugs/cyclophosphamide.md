## Cyclophosphamide: Vertebral anomalies and variable endocrine and T-cell dysfunction
{: .text-alpha }

## Résumé en Une Phrase

Le cyclophosphamide est un agent alkylant cytotoxique utilisé en oncologie et comme immunosuppresseur.
Le modèle TxGNN prédit qu'il pourrait être utile pour **vertebral anomalies and variable endocrine and T-cell dysfunction (anomalies vertébrales avec dysfonction endocrinienne et des lymphocytes T variable)**, avec un score de 0,9938.
Aucun essai clinique ni aucune publication ne soutient actuellement cette prédiction : il s'agit d'une prédiction du modèle uniquement.

## Pourquoi Cette Prédiction est-elle Raisonnable ?

Actuellement, les données détaillées sur le mécanisme d'action ne sont pas disponibles. D'après les informations connues, le cyclophosphamide est un agent alkylant à effet cytotoxique et immunosuppresseur.

Aucun lien mécanistique n'a pu être établi avec cette pathologie. Il s'agit d'un syndrome congénital rare associant anomalies vertébrales, troubles endocriniens variables et dysfonction des lymphocytes T. Un agent alkylant cytotoxique n'est pas un candidat évident pour ce type d'affection. Le score élevé du modèle reste une simple prédiction, sans étude réelle pour la corroborer. La similarité avec les indications d'origine n'a pas été évaluée.

**Interactions médicamenteuses** (100 interactions recensées ; principales d'après les données compilées) :
- Niveau modéré : amphotéricine B (y compris formes lipidiques, liposomale et sulfate de cholestéryle), bupropion, aprépitant, métronidazole, nitisinone, ainsi que des antidiabétiques (sulfamides hypoglycémiants comme glimépiride, glipizide, glibenclamide, chlorpropamide, tolbutamide ; répaglinide, natéglinide ; troglitazone).
